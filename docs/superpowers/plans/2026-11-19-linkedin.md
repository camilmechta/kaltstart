# LinkedIn Messages Implementation Plan

> **For agentic workers:** executed natively in the session, test first.

**Goal:** a LinkedIn channel: a connection note of at most 200 characters and a follow-up message, kept and tracked like a mail.

**Spec:** `docs/superpowers/specs/2026-11-19-linkedin-design.md`

## Tasks

1. **Generator** (`src/kaltstart/mailgen/linkedin.py`, tests `tests/mailgen/test_linkedin.py`):
   `linkedin_note(student, company, round, person_name, style, language) -> str` (candidate ladder, first that fits `MAX_NOTE_CHARS = 200`, a last candidate without names);
   `linkedin_message(student, company, round, person_name, style, language, company_line, variant) -> str` (at most `MAX_MESSAGE_WORDS`).
   Exhaustive matrix test with the longest inputs of `tests/mailgen/test_matrix.py`.
2. **Compose and pages** (`api/compose.py`, `api/pages.py`, `templates/company.html`):
   form field `channel` (`email` | `linkedin`); LinkedIn refused for `team` and for named list choices at a large company (D100);
   recipient address None, type `linkedin`; preview shows the note, its character count and the message; keep stores subject = note, body = message.
3. **Kept page and My mails** (`templates/mail.html`, `mails.html`): labels "Connection note" and "Message", copy buttons, the LinkedIn people search link (URL-encoded), four steps; "To Anna Muster, on LinkedIn".
4. **Migration 0011** (`address_type` gains `linkedin`), check column `m0011_linkedin`, SQL test; `/privacy` sentence.
5. Local check, D101, changelog, Opus review, owner pastes 0011, push with approval.
